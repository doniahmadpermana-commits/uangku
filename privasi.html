Kebijakan Privasi

Berlaku sejak 9 November 2026

Singkatnya
  • Uangku gratis, tanpa iklan, dan tanpa pelacak / analitik.
  • Datamu tidak dijual dan tidak dibagikan untuk iklan atau pemasaran.
  • Tanpa akun, data hanya ada di perangkatmu. Dengan akun, data disimpan di server Google (Firebase).
  • Kamu bisa menghapus semua data dan akunmu kapan saja dari menu Atur.

1. Data yang dicatat

Uangku hanya menyimpan apa yang kamu isi sendiri:

  • Catatan transaksi: jumlah, jenis (masuk / keluar / pindah), kategori, tanggal, dan catatan.
  • Dompet (nama, ikon, saldo awal), kategori buatan sendiri, dan budget bulanan.
  • Jika membuat akun: alamat email dan password.

Uangku tidak meminta nama asli, nomor HP, lokasi, kontak, atau akses ke rekening bank / e-wallet-mu. Saldo di aplikasi hanyalah angka yang kamu catat sendiri.

2. Tanpa akun

Semua data tersimpan di penyimpanan browser di perangkatmu dan tidak dikirim ke server mana pun. Data ini bisa hilang jika kamu menghapus aplikasi, data situs, atau riwayat browser, atau jika perangkat hilang. Gunakan Atur → Backup data secara berkala.

3. Dengan akun

  • Email dan password dikelola oleh Firebase Authentication (Google). Password disimpan dalam bentuk terenkripsi oleh Google; pengelola Uangku tidak bisa melihatnya.
  • Data catatanmu disimpan di Cloud Firestore (Google Cloud) di region Jakarta (asia-southeast2), supaya bisa dibuka dari beberapa perangkat.
  • Data dikirim lewat koneksi terenkripsi (HTTPS) dan disimpan terenkripsi oleh Google.
  • Email yang dikirim hanya email sistem: verifikasi email dan reset password. Tidak ada email promosi.

4. Siapa yang bisa melihat datamu

  • Pengguna lain tidak bisa. Aturan keamanan database membatasi setiap akun hanya bisa membaca dan mengubah datanya sendiri.
  • Pengelola Uangku secara teknis bisa mengakses data di database melalui konsol Firebase, karena datamu tidak dienkripsi end-to-end. Kami tidak membuka data pengguna, kecuali kamu sendiri yang meminta bantuan terkait datamu atau diwajibkan oleh hukum yang berlaku.
  • Google memproses data sebagai penyedia layanan (Firebase / Google Cloud) sesuai ketentuan privasi Firebase.
  • Situs ini di-hosting oleh GitHub Pages, yang dapat mencatat data teknis standar seperti alamat IP saat halaman dibuka.

5. Menghapus data

  • Atur → Hapus semua data: menghapus semua catatan, dompet, dan kategori. Jika sedang masuk akun, data di cloud ikut terhapus dari semua perangkat.
  • Atur → Hapus akun & semua datanya: menghapus akun beserta seluruh datanya di cloud secara permanen.
  • Tanpa akun: hapus aplikasi atau data situs di browser.

Penghapusan bersifat permanen dan tidak bisa dibatalkan. Buat backup dulu jika masih perlu.

6. Batasan layanan

Uangku adalah layanan gratis yang disediakan sebagaimana adanya. Kami berusaha menjaga data tetap aman, tetapi tidak ada sistem yang kebal dari gangguan, dan server tidak menyimpan cadangan otomatis. Simpan backup berkala (aplikasi akan mengingatkan setiap bulan). Uangku bukan aplikasi bank dan tidak terhubung ke rekeningmu.

7. Perubahan & kontak

Kebijakan ini bisa diperbarui sewaktu-waktu; tanggal berlaku di atas akan ikut berubah. Pertanyaan atau permintaan terkait data bisa disampaikan lewat halaman Issues proyek Uangku di GitHub. Jangan menulis data pribadi atau isi catatan keuanganmu di sana, karena halaman itu publik.
